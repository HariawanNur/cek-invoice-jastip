# 🚀 Universal Order & Invoice Tracking Portal (Multi-Bisnis SaaS)

Aplikasi Web Portal All-in-One untuk **SEMUA Jenis Bisnis & UMKM** (Toko Online, Servis HP/Laptop, Kuliner & Katering, Percetakan & Sablon, Digital Agency/Jasa, hingga Jasa Titip/Jastip). 

Dirancang dengan tampilan mobile-first bergaya fintech modern, fitur tracking transparan, PDF invoice otomatis, dan backend **100% GRATIS** menggunakan Google Sheets (tanpa biaya sewa server atau database SQL bulanan).

---

## 💎 Kenapa Aplikasi Ini Bernilai Jual Tinggi?
Hampir semua pemilik usaha di Indonesia mengelola pesanan lewat WhatsApp dan Google Sheets. Masalah utamanya adalah **kewalahan membalas chat berulang**:
- *"Kak, pesanan / servis / cetakan saya sudah sampai mana?"*
- *"Kak, total tagihan saya berapa ya?"*
- *"Kak, minta nomor rekening transfernya dong?"*
- *"Kak, nomor resi pengiriman mana ya?"*

**Aplikasi ini menyelesaikan masalah tersebut dengan 1 link web portal instan!** Anda dapat menjual jasa pemasangan web portal ini ke berbagai jenis owner bisnis dengan harga **Rp 500.000 – Rp 2.500.000** per klien.

## ✨ Fitur-Fitur Unggulan (Commercial-Ready)

### 1. 🧾 Desain E-Receipt Mewah dengan Barcode & Stempel Basah
- Tampilan nota kasir boutique dengan pola zig-zag autentik dan visual barcode.
- **Stempel Basah Otomatis**: Menampilkan cap `✓ LUNAS / PAID` (hijau), `DP TERBAYAR` (kuning/emas), atau `BELUM BAYAR` (merah).
- **Cetak Struk Thermal**: Tombol `🖨️ Cetak Struk` langsung siap cetak ke printer kasir / thermal via `@media print`.
- **Download PDF A5**: Tombol `📄 Download PDF` untuk generate dokumen invoice resmi.
- **Deep-Linking URL**: Cukup kirim link `website.com/?hp=08123456789` via WhatsApp, customer klik dan invoice langsung terbuka tanpa perlu mengetik ulang!

### 2. 👑 Portal Pemilik Toko & Kasir (In-Browser Admin Dashboard)
- Akses khusus pemilik bisnis dilindungi **PIN Keamanan** (Default: `1234`, bisa diganti).
- **Statistik Finansial Real-time**: Total Omset Transaksi (Rp), Piutang Belum Lunas (Rp), Order Lunas, dan Paket Perlu Resi / Diambil.
- **Filter Cepat**: Semua, Belum Bayar, DP Terbayar, Lunas, dan Butuh Resi.
- **Aksi Cepat 1-Klik**:
  - Ubah status Lunas / Batal Lunas langsung dari tabel.
  - Edit nilai DP, Diskon, Ongkir, Kurir Ekspedisi, dan Nomor Resi.
  - Update tahapan pengerjaan (Diterima, Diproses, Dikirim, Selesai).
  - Buka langsung tampilan invoice pelanggan.
  - Kirim Notifikasi WA Otomatis (Rincian Tagihan, Info Nomor Resi, atau Konfirmasi Lunas).
- **Buat Invoice Manual**: Admin bisa menerbitkan invoice langsung untuk pelanggan yang order via WhatsApp atau kasir offline.
- **Export Laporan CSV / Excel**: Unduh rekap penjualan toko dalam format spreadsheet dalam 1 klik.

### 3. 🎨 Live Brand & Color Palette Customizer
- Pilihan 5 palet warna fintech modern: **Indigo Blue, Emerald Green, Ocean Teal, Rose Ruby, Amber Gold**.
- Fitur ganti nama toko langsung di browser saat demo ke calon klien.
- Toggle Mode Pengiriman Kurir vs Ambil di Workshop (Opsi A).
- Dukungan **Dark Mode & Light Mode**.

### 4. 🚚 Pelacakan Nomor Resi / Referensi Pengantaran
- Menampilkan nomor resi (SiCepat, J&T, JNE, Gosend, Grab, Dakota Cargo).
- Tombol **1-Klik Salin Resi** dan link langsung cek ke pelacak ekspedisi `cekresi.com`.
- Otomatis disembunyikan jika bisnis bertipe non-fisik/ambil di workshop (servis, digital agency).

### 5. 💳 Payment Hub & 1-Klik Salin Rekening
- Kartu rekening resmi toko (BCA, Mandiri, SeaBank, QRIS All Payment).
- Salin nomor rekening dengan 1 klik disertai toast notifikasi.
- Modal preview **QRIS Universal** (bisa discan dari BCA Mobile, Livin, GoPay, OVO, ShopeePay, Dana).

### 6. 🛒 Formulir Pemesanan Dinamis (Multi-Item)
- Tambah & hapus banyak item dalam satu form dengan Qty counter (+/-).
- Kolom Nama Produk/Layanan, Brand/Kategori, Varian/Kerusakan, Ukuran/Porsi, dan Catatan Khusus.
- Honeypot anti-spam tersembunyi untuk mencegah bot.
- Efek selebrasi **Confetti 🎉** saat pesanan berhasil dikirim.

## 🛠️ Cara Kustomisasi untuk Klien

Semua konfigurasi terpusat di file [`src/config.js`](file:///src/config.js):
- Ubah nomor WhatsApp admin di `ADMIN_WA`.
- Ubah nama usaha, tagline, dan rekening bank di `BUSINESS_PRESETS` & `DEFAULT_BANKS`.
- Masukkan URL backend Google Sheets di `API_URL`.

---

## 📊 Setup Backend Google Sheets (2 Menit)

1. Buat Spreadsheet baru di Google Sheets milik klien.
2. Klik **Ekstensi > Apps Script**.
3. Hapus kode bawaan, lalu salin dan tempel seluruh isi file [`apps-script/Code.gs`](file:///apps-script/Code.gs).
4. Pilih fungsi `setupSheetOtomatis` dan klik **Run** untuk membuat header tabel berwarna otomatis.
5. Klik tombol **Deploy > New deployment**:
   - Pilih tipe: **Web app**
   - Execute as: **Me**
   - Who has access: **Anyone**
6. Salin Web App URL yang dihasilkan, lalu tempelkan ke `API_URL` di [`src/config.js`](file:///src/config.js).

## ⚡ Menjalankan Proyek & Build

```bash
# Pasang dependensi
npm install

# Jalankan server lokal (development)
npm run dev

# Build untuk produksi hosting
npm run build
```

Hasil build berada di folder `dist/` dan siap diunggah ke Vercel, Netlify, Cloudflare Pages, atau hosting cPanel apa pun secara gratis!
